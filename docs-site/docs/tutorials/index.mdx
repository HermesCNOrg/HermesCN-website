## 学习路线

| 阶段 | 课程 | 你会完成什么 |
| --- | --- | --- |
| **第一阶段 · 成功与安全** | 01—05 | 完成首次对话和第一个可验证任务，理解权限与安全边界 |
| **第二阶段 · 日常方法** | 06—10 | 学会描述任务、管理会话、选择工具并处理失败 |
| **第三阶段 · 接入与自动化** | 11—13 | 接入飞书，配置定时任务并处理语音、图片和文件 |
| **第四阶段 · 扩展与协作** | 14—16 | 使用子代理与 Profiles，选择合适的扩展方式 |
| **第五阶段 · 综合实战** | 17—18 | 完成资料整理和每日研究助手两个完整项目 |
